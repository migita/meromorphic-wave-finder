# Meromorphic wave finder (preview)

Static site: for an autonomous polynomial ordinary differential equation (for example the travelling-wave
reduction of an evolution equation) it reports the meromorphic solutions that are found, the kinds of
solutions that are ruled out, and what is not decided. Every item carries a label that says what it rests on.

Site: https://migita.github.io/meromorphic-wave-finder/

This is a preview. Results labelled "agent-proof" have not been checked by a person.
